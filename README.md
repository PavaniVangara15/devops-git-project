# DevOps Git Workflow Project

This project demonstrates a version-controlled DevOps workflow using Git and GitHub.

## Branching Strategy

- `main`: Stable, production-ready code.
- `dev`: Integration and testing branch.
- `feature/*`: Individual tasks and features.

## How to Contribute

1. Create a branch from `dev`.
2. Commit changes with clear messages.
3. Open a Pull Request to `dev`.
4. After testing, promote `dev` to `main` via PR.
